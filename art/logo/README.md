# Just Enough Juices branding

Original pixel-style lettering and fruit-bottle artwork, with a forest-green
outline, citrus-gold highlights, orange juice, and mint leaves.

- `just-enough-juices-logo.png`: transparent 1200 × 600 wordmark.
- `just-enough-juices-logo.svg`: editable vector wordmark.
- `just-enough-juices-icon.png`: 512 × 512 square project icon.
- `just-enough-juices-icon.svg`: editable vector icon.
- `just-enough-juices-bottle.png`: transparent 384 × 384 bottle-only icon.
- `just-enough-juices-bottle.svg`: scalable bottle-only artwork.
- `just-enough-juices-bottle-{512,256,128,64,32}.png`: square transparent icons,
  with no text, background, or sparkles.

Regenerate with `python3 tools/create_logo.py` (Pillow required). No external fonts
or stock artwork are used. These are standalone branding assets; mod metadata
and existing game textures are unchanged.
